# FrameFlow v1.5.6 发布说明

> FrameFlow（帧流）— 一款基于 Flutter 开发的跨平台图片幻灯片播放器。
> 本应用无广告、完全免费，可自由分享。

---

## 🎉 本版本主题：一个应用，多个图片库

v1.5.6 新增**多媒体库**：可以把不同的文件夹分组为多个独立的库（例如「家庭」「工作」「壁纸」），一键切换；每个库有自己独立的文件夹、共享源和已排除记录。同时修复了浏览页排除图片后的加载异常，以及共享文件夹跨库切换后的在线状态误判。

---

## ✨ 新增功能

### 📚 多媒体库

- 文件夹选择页右上角新增**媒体库**按钮，可新建、重命名、删除、隐藏媒体库，并随时切换。
- 每个媒体库独立保存：本地文件夹、局域网共享文件夹、已排除图片。
- 启动页标题会显示当前媒体库名称，切换后立即刷新文件夹列表与统计。
- 设置 → 文件管理 新增 **显示隐藏媒体库**：关闭后隐藏的库不在列表中显示，也不参与自动匹配。

### 🖱 双击 / 右键打开图片自动切库

- 在资源管理器中双击图片（或右键「用 FrameFlow 打开」）时，会自动切换到该图片所属的媒体库并开始播放，不再受当前库限制。
- 若图片不在任何库中（或所属库被隐藏），则按当前库继续处理。

### 📱 手机端同名文件夹归并

- Android 上同名相册的所有路径会合并为一个条目管理，浏览与播放时自动合并去重，避免同一相册重复出现。

### 🤝 帮助页与 README 新增姐妹应用

- 帮助页「关于」与项目 README 增加姐妹应用 **SteamFlow**（跨平台视频幻灯片播放器）的简介与链接。
- 图片用 FrameFlow，视频用 SteamFlow。

---

## 🐛 问题修复

- **浏览页排除图片后一直加载**：在图片瀑布流中中途排除或删除图片后，滚动到底部会一直显示加载提示；现在排除后会同步分页计数，加载提示可以正常结束。
- **共享文件夹跨库切换后状态错误**：切换媒体库后，原库中已被对方取消共享的文件夹仍显示为在线并出现播放按钮；现在会逐文件夹校验远端共享状态，不再共享时按离线处理（灰显 + 刷新按钮）。
- **子文件夹为 0 时的统计文案**：文件夹统计不再显示「包含 0 个子文件夹」，直接显示「包含 N 个文件」。

---

## 🔄 升级说明

- 旧版本的设置、已选文件夹、共享源与已排除记录都会自动迁移到默认媒体库，无需重新配置。
- 从 v1.5.x 升级可直接覆盖安装。

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `FrameFlow-v1.5.6-windows-x64.zip` | 解压后运行 `FrameFlow.exe`（64 位） |
| **Android** | `FrameFlow-v1.5.6-android.apk` | APK 安装包（需允许「安装未知来源应用」） |

### Windows 安装说明

1. 下载 `FrameFlow-v1.5.6-windows-x64.zip`
2. 解压到任意目录
3. 双击运行 `FrameFlow.exe` 即可使用

### Android 安装说明

1. 下载 `FrameFlow-v1.5.6-android.apk`
2. 将 APK 传输至手机，或直接用手机浏览器下载
3. 点击安装；如提示「未知来源」，请在系统设置中允许该应用的「安装未知应用」权限

## 📝 功能特性一览

- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新图优先 等多种播放顺序，循环播放、自动播放、播放时自动全屏、换片时间可调（1 秒 ~ 10 分钟，或自定义）
- **图片显示**：适应窗口 / 填满窗口 / 原图大小、多种背景色、屏幕方向控制、缩放（最高 5 倍）/ 旋转 / 拖拽平移
- **瀑布流浏览**：本地与共享文件夹统一的 7 种排序、6 种画幅、卡片文件信息、按当前排序播放、单张复制、复制整个文件夹
- **多媒体库**：多库切换、重命名 / 删除 / 隐藏、打开图片自动切库、排除记录按库隔离
- **鼠标与触控板**：滚轮可设为换片或缩放（`Ctrl`/`Shift` 反向）、触控板捏合缩放、右键菜单、放大后左键拖动平移、拖到边缘松手切图
- **切换动画**：淡入淡出、左右滑动、上下滑动、无动画，动画时长可调（0.1 ~ 1.0 秒）
- **全屏模式**：真·全屏（Windows）、工具栏自动隐藏、暂停时保持工具栏、播放页直接关闭
- **多目录支持**：支持多个文件夹、包含子文件夹、文件去重、实时统计
- **内网共享**：跨设备共享文件夹、自动发现、混合播放、远程排除播放 / 远程复制（共享方可控）、断连重连、封面缓存
- **图片管理**：排除播放、实际删除（`Ctrl+Del` 反向）、已排除图片按文件夹分组管理（恢复 / 删除 / 复制到 / 剪切到）
- **系统托盘**：桌面端可选择关闭窗口后继续在托盘运行，便于持续共享
- **信息显示**：文件名、大小、分辨率、页码，信息条自动隐藏
- **丰富快捷键**：Space 播放暂停、←→ 切换、↑↓ 缩放、R/L 旋转、`Ctrl`+`=`/`-`/`0` 缩放、F11 全屏、Del 排除/删除等
- **设置持久化**：所有设置自动保存，下次启动自动恢复
- **多语言**：简体中文 / 繁體中文 / English
- **帮助页**：内置说明文档 / 关于 / 赞助

## 🔧 技术栈

- 框架：Flutter 3.x
- 语言：Dart
- 状态管理：Provider
- 本地存储：SharedPreferences
- 网络：Dart `HttpServer` / `HttpClient` + UDP 设备发现
- 文件选择：FilePicker
- 平台支持：Windows / macOS / Linux / Android / iOS
