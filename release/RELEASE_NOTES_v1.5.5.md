# FrameFlow v1.5.5 发布说明

> FrameFlow（帧流）— 一款基于 Flutter 开发的跨平台图片幻灯片播放器。
> 本应用无广告、完全免费，可自由分享。

---

## 🎉 本版本主题：和系统贴得更近，看图更顺手

v1.5.5 把 FrameFlow 正式接入 Windows 资源管理器：右键就能用 FrameFlow 打开图片，也可以把它设为图片格式的默认打开程序。同时补上了浏览页的画幅与文件信息、手机端短按行为、桌面播放器关闭按钮等一批日常使用细节，并修正了中文文件名的排序问题。

---

## ✨ 新增功能

### 🖱 右键菜单「用 FrameFlow 打开」

- 设置 → 快捷键与控制 → **添加到右键菜单**（仅 Windows），打开后会为 jpg / jpeg / png / webp / bmp / gif 六种图片格式注册右键菜单项。
- 在资源管理器中右键任意受支持的图片，即可选择「用 FrameFlow 打开」，应用启动后直接全屏播放该图片。
- 菜单文字会跟随界面语言自动切换（简体 / 繁体 / English）。

### 🖥 设为图片默认打开程序

- 设置中新增 **设为默认打开程序 → 去设置** 按钮，点击后会把 FrameFlow 注册为候选图片浏览器，并打开系统的「默认应用」页面，按提示选择 FrameFlow 即可。
- 只做候选注册，不会擅自替换你现有的默认看图软件，最终由你在系统里确认。

### 🚀 单实例与命令行打开

- 应用现在只允许运行一个窗口：重复启动时会唤醒已有窗口，而不是再开一个。
- 从右键菜单打开图片时，会把文件直接交给已运行的 FrameFlow 播放，不会出现第二个托盘图标或第二份共享服务。
- 启动时带图片路径参数（例如在终端执行 `FrameFlow.exe "D:\照片\a.jpg"`）同样可以直接播放该图片。

### 🎞 浏览格式与文件列表信息

- 设置 → 文件管理 新增两个选项：
  - **文件列表信息**：无 / 仅文件名 / 文件名 + 日期 + 大小，在瀑布流卡片下方显示。
  - **浏览格式**：瀑布流 / 正方形 / 4:3 横图 / 16:9 横图 / 3:4 竖图 / 9:16 竖图，统一本地与共享浏览页的画幅。
- 浏览页右上角的排序按钮改为**显示当前排序方式的图标**，不用展开菜单也能一眼看出当前排序。

### 👆 手机端短按行为

- 设置 → 快捷键与控制 新增 **短按行为**：
  - **播放**：点击文件即播放，长按用于选中；
  - **选中**：点击用于选中，长按或再次点击开始播放（默认）。

### ⏻ 桌面播放器关闭按钮

- 全屏播放页右上角新增关闭按钮，不必先退出全屏再关窗口。
- 关闭行为遵循「关闭时最小化到托盘」设置：开启则收起到系统托盘，关闭则直接退出。

## 🐛 问题修复

- **中文文件名排序错误**：之前按字符编码排序，会出现「吧」排在「啊」前面这类结果；现在 Windows 上使用与资源管理器一致的规则（中文按拼音、数字按自然顺序、大小写不敏感），播放顺序、浏览排序、共享列表排序与增量插入位置全部统一。非 Windows 平台回退为内置的自然排序，数字序号（如 `1、2、10`）也不会再乱序。
- **英文版主界面按钮溢出**：窗口或屏幕较窄时，英文长文案会撑破按钮；现在按钮内边距收窄，文字过长时自动省略，不再出现黄色溢出条。
- **右键菜单与默认程序文案本地化**：菜单标题、文件类型名、「默认应用」中的应用说明都会按当前语言写入，切换语言后自动更新。

## 🔄 行为说明

- 「添加到右键菜单」默认关闭，需要时在设置中开启；关闭后会把相关注册表项一并清理。
- 所有系统注册均写入当前用户（HKCU），不需要管理员权限，也不会影响其他用户。
- 旧版本的设置、已选文件夹、已排除记录完整保留，可直接覆盖安装。

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `FrameFlow-v1.5.5-windows-x64.zip` | 解压后运行 `FrameFlow.exe`（64 位） |
| **Android** | `FrameFlow-v1.5.5-android.apk` | APK 安装包（需允许「安装未知来源应用」） |

### Windows 安装说明

1. 下载 `FrameFlow-v1.5.5-windows-x64.zip`
2. 解压到任意目录
3. 双击运行 `FrameFlow.exe` 即可使用

> 若开启了右键菜单或默认程序注册，请把程序放在固定目录再设置；移动或删除 exe 后需重新开启一次，以刷新注册路径。

### Android 安装说明

1. 下载 `FrameFlow-v1.5.5-android.apk`
2. 将 APK 传输至手机，或直接用手机浏览器下载
3. 点击安装；如提示「未知来源」，请在系统设置中允许该应用的「安装未知应用」权限

> 从 v1.5.x 升级可直接覆盖安装，设置、已选文件夹与排除记录都会保留。

## 📝 功能特性一览

- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新图优先 等多种播放顺序，循环播放、自动播放、播放时自动全屏、换片时间可调（1 秒 ~ 10 分钟，或自定义）
- **图片显示**：适应窗口 / 填满窗口 / 原图大小、多种背景色、屏幕方向控制、缩放（最高 5 倍）/ 旋转 / 拖拽平移
- **瀑布流浏览**：本地与共享文件夹统一的 7 种排序、6 种画幅、卡片文件信息、按当前排序播放、单张复制、复制整个文件夹
- **鼠标与触控板**：滚轮可设为换片或缩放（`Ctrl`/`Shift` 反向）、触控板捏合缩放、右键菜单、放大后左键拖动平移、拖到边缘松手切图
- **切换动画**：淡入淡出、左右滑动、上下滑动、无动画，动画时长可调（0.1 ~ 1.0 秒）
- **全屏模式**：真·全屏（Windows）、工具栏自动隐藏、暂停时保持工具栏、播放页直接关闭
- **多目录支持**：支持多个文件夹、包含子文件夹、文件去重、实时统计
- **内网共享**：跨设备共享文件夹、自动发现、混合播放、远程排除播放 / 远程复制（共享方可控）、断连重连、封面缓存
- **图片管理**：排除播放、实际删除（`Ctrl+Del` 反向）、已排除图片按文件夹分组管理（恢复 / 删除 / 复制到 / 剪切到）
- **系统托盘**：桌面端可选择关闭窗口后继续在托盘运行，便于持续共享
- **信息显示**：文件名、大小、分辨率、页码，信息条自动隐藏
- **丰富快捷键**：Space 播放暂停、←→ 切换、↑↓ 缩放、R/L 旋转、`Ctrl`+`=`/`-`/`0` 缩放、F11 全屏、Del 排除/删除等
- **设置持久化**：所有设置自动保存，下次启动自动恢复
- **多语言**：简体中文 / 繁體中文 / English
- **帮助页**：内置说明文档 / 关于 / 赞助

## 🔧 技术栈

- 框架：Flutter 3.x
- 语言：Dart
- 状态管理：Provider
- 本地存储：SharedPreferences
- 网络：Dart `HttpServer` / `HttpClient` + UDP 设备发现

- 平台支持：Windows / macOS / Linux / Android / iOS
