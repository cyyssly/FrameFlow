# FrameFlow v1.5.7 发布说明

> FrameFlow（帧流）— 一款基于 Flutter 开发的跨平台图片幻灯片播放器。

## 🎉 本版本主题：修复退出播放页黑屏

v1.5.7 是一个**问题修复版本**，主要解决「双击打开图片后按 ESC 退出，界面变黑而不是回到主菜单」的问题。

---

## 🐛 问题修复

### ⌨️ ESC 退出播放页后黑屏

- **现象**：双击图片（或右键「用 FrameFlow 打开」）进入播放页后，按 `Esc`（或在退场动画期间连按 `Esc`、重复点击左上角返回按钮），窗口会变成全黑，只能重新启动应用。
- **原因**：退出播放页时有一段退场动画，动画期间播放页仍在响应键盘。此时再次按 `Esc` 会多执行一次返回，把播放页下面的主界面也一起关掉，导航栈变空后画面就是纯黑。
- **修复**：退出动作现在只会执行一次，重复的 `Esc` / 返回点击会被忽略；同时若播放页已是导航栈中唯一的页面，会直接切换到主界面而不是关闭最后一页，任何情况下都不会再出现黑屏。

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `FrameFlow-v1.5.7-windows-x64.zip` | 解压后运行 `FrameFlow.exe`（64 位） |
| **Android** | `FrameFlow-v1.5.7-android.apk` | APK 安装包（需允许「安装未知来源应用」） |

### Windows 安装说明

1. 下载 `FrameFlow-v1.5.7-windows-x64.zip`
2. 解压到任意目录
3. 双击运行 `FrameFlow.exe` 即可使用

### Android 安装说明

1. 下载 `FrameFlow-v1.5.7-android.apk`
2. 将 APK 传输至手机，或直接用手机浏览器下载
3. 点击安装；如提示「未知来源」，请在系统设置中允许该应用的「安装未知应用」权限

## 🔧 技术栈

- 框架：Flutter 3.x
- 语言：Dart
- 状态管理：Provider
- 本地存储：SharedPreferences
- 网络：Dart `HttpServer` / `HttpClient` + UDP 设备发现
- 文件选择：FilePicker
- 平台支持：Windows / macOS / Linux / Android / iOS
