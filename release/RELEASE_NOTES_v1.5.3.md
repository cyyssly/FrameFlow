# FrameFlow v1.5.3 发布说明

> FrameFlow（帧流）— 一款基于 Flutter 开发的跨平台图片幻灯片播放器。
> 本应用无广告、完全免费，可自由分享。

---

## 🎉 本版本主题：内网共享更好用，操作更不容易误触

v1.5.3 重点增强了**内网共享的远程管理能力**：共享图片不再只能看，其他终端可以在共享方允许的前提下远程「排除播放」或「复制」；同时桌面端新增**关闭窗口收起到系统托盘**，让共享服务在后台持续可用。选择图片页也做了一轮精简，减少批量操作带来的误触风险。

---

## ✨ 新增功能

### 🌐 内网共享：远程排除播放与远程复制

内网共享页面现在有 4 个开关（全部默认关闭）：

| 开关 | 说明 |
|------|------|
| **共享本机图片** | 打开后其他终端可浏览本机的共享文件夹 |
| **允许远程排除播放** | 其他终端可把共享图片标记为「排除播放」（不会删除文件） |
| **允许远程复制** | 其他终端可把共享图片复制到自己的设备 |
| **关闭时最小化到托盘**（仅 Windows） | 点击关闭按钮时收起到系统托盘，共享服务继续运行 |

- **被远程排除的图片，会记录在共享方本机的「已排除文件」中**，与本地排除的处理完全一致：播放、瀑布流都会自动过滤，随时可以一键恢复，磁盘上的原图不受影响。
- 共享终端会把自己的能力同步给访问方，访问方按能力显示按钮：
  - 只开启「远程排除播放」→ 显示橙色排除按钮；
  - 只开启「远程复制」→ 显示绿色复制按钮；
  - 两个都开启 → 排除按钮在前、复制按钮在后；
  - 两个都关闭 → 共享图片上不显示任何操作按钮。
- 远程操作同样遵循「共享方说了算」：开关关闭时，远端请求会被直接拒绝。

### 🖥 桌面端：关闭窗口收起到系统托盘

- 在内网共享页打开「关闭时最小化到托盘」后，点击窗口右上角关闭按钮不再退出程序，而是收起到系统托盘继续运行，其他终端仍可浏览本机图片。
- 托盘图标支持**左键单击显示主界面**，**右键弹出菜单**（显示主界面 / 退出）。
- 该选项默认关闭，保持原有的「关闭即退出」行为。

### 📍 共享页直接显示本机地址

- 「共享本机图片」的副标题直接显示当前供其他终端访问的内网地址，去掉了下方单独一行的地址提示，信息更集中。

## 🧹 界面与交互精简（降低误操作）

选择图片页面：

- 文件夹右侧原来的「排除播放」按钮改名为 **「取消管理」**，并换用了与排除操作不同的图标，避免被误认为批量排除图片。
- 取消了底部大按钮 **「全部排除」**。
- 取消了本地文件夹标题、共享文件夹标题上的批量排除按钮。
- 取消了「已排除文件」分组标题上的 **「删除全部」**。
- 保留下来的「播放全部 / 重新连接全部 / 恢复全部」按钮移到标题文字之后，不再放在行尾，操作位置更直观。
- 单个文件夹、单条已排除文件的「取消管理 / 恢复文件 / 删除文件」操作保持不变。

## 🐛 问题修复

- **已排除文件分组内容串台**：之前点击任意一个已排除文件夹分组，进入后都显示全部已排除文件；现在只显示该分组下的文件，分组内的批量操作也只作用于当前分组。
- **手机端同名目录重复分组**：手机端扫描到的同名目录即使路径不同，也合并为同一分组管理，避免出现多行同名条目。

---

## 🔄 行为说明

- 内网共享服务的远程接口只做「排除播放」这一种写操作，**不会删除、修改或移动共享方磁盘上的任何文件**。
- 远程排除记录保存在共享方本机，排除后立即从远端列表和播放中移除。
- 「允许远程排除播放」「允许远程复制」「关闭时最小化到托盘」三个新选项均默认关闭，升级后行为与旧版本一致，需要时再手动开启。
- 旧版本的设置、已选文件夹、已排除记录会完整保留，可直接覆盖安装。

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `FrameFlow-v1.5.3-windows-x64.zip` | 解压后运行 `FrameFlow.exe`（64 位） |
| **Android** | `FrameFlow-v1.5.3-android.apk` | APK 安装包（需允许「安装未知来源应用」） |

### Windows 安装说明

1. 下载 `FrameFlow-v1.5.3-windows-x64.zip`
2. 解压到任意目录
3. 双击运行 `FrameFlow.exe` 即可使用

### Android 安装说明

1. 下载 `FrameFlow-v1.5.3-android.apk`
2. 将 APK 传输至手机，或直接用手机浏览器下载
3. 点击安装；如提示「未知来源」，请在系统设置中允许该应用的「安装未知应用」权限

> 从 v1.5.x 升级可直接覆盖安装，设置、已选文件夹与排除记录都会保留。

## 📝 功能特性一览

- **播放控制**：顺序 / 逆序 / 由新到旧 / 由旧到新 / 随机 / 新图优先 等多种播放顺序，循环播放、自动播放、播放时自动全屏、换片时间可调（1 秒 ~ 10 分钟，或自定义）
- **图片显示**：适应窗口 / 填满窗口 / 原图大小、多种背景色、屏幕方向控制、缩放（最高 5 倍）/ 旋转 / 拖拽平移
- **瀑布流浏览**：本地与共享文件夹统一的 7 种排序、按当前排序播放、单张复制、复制整个文件夹
- **鼠标与触控板**：滚轮可设为换片或缩放（`Ctrl`/`Shift` 反向）、触控板捏合缩放、右键菜单、放大后左键拖动平移、拖到边缘松手切图
- **切换动画**：淡入淡出、左右滑动、上下滑动、无动画，动画时长可调（0.1 ~ 1.0 秒）
- **全屏模式**：真·全屏（Windows）、工具栏自动隐藏、暂停时保持工具栏
- **多目录支持**：支持多个文件夹、包含子文件夹、文件去重、实时统计
- **内网共享**：跨设备共享文件夹、自动发现、混合播放、远程排除播放 / 远程复制（共享方可控）、断连重连、封面缓存
- **图片管理**：排除播放、实际删除（`Ctrl+Del` 反向）、已排除图片按文件夹分组管理（恢复 / 删除 / 复制到 / 剪切到）
- **系统托盘**：桌面端可选择关闭窗口后继续在托盘运行，便于持续共享
- **信息显示**：文件名、大小、分辨率、页码，信息条自动隐藏
- **丰富快捷键**：Space 播放暂停、←→ 切换、↑↓ 缩放、R/L 旋转、`Ctrl`+`=`/`-`/`0` 缩放、F11 全屏、Del 排除/删除等
- **设置持久化**：所有设置自动保存，下次启动自动恢复
- **多语言**：简体中文 / 繁體中文 / English
- **帮助页**：内置说明文档 / 关于 / 赞助
