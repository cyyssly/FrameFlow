# FrameFlow v1.6.0 发布说明

> FrameFlow（帧流）— 跨平台图片幻灯片播放器。无广告、完全免费。

---

## 本版本主题：同名文件夹合并管理

v1.6.0 是一个**管理体验升级 + 问题修复**版本。

---

## ✨ 新增与改进

### 📁 同名文件夹合并成一个条目

手机相册里经常出现 `Camera`、`camera` 这类只有大小写不同的同名文件夹。现在它们会像 SteamFlow 一样**合并成一个条目**：

- **选择文件夹页**：只显示一个条目，组内所有图片统一浏览、统一统计、统一播放
- **内网共享页**：同名文件夹只共享一次，不再出现多个重复条目
- **已排除图片分区**：同名文件夹的排除记录归到同一组，仅大小写差异也视为同名
- **桌面端读取手机共享源**：服务端已合并，桌面端看到的就是一个文件夹

移除共享、添加播放列表等操作都以合并后的条目为单位，不会再出现「删了一个还剩几个」的情况。

### ❓ 复制 / 移动遇到同名文件时先询问

以前目标位置已有同名文件会静默改名复制，容易产生一堆 `xxx(1).jpg`。现在改为弹窗由你决定：

- **单张**：替换 / 跳过 / 取消
- **批量**：弹窗会提示共有多少张同名文件，可选「全部替换 / 全部跳过 / 替换本张 / 跳过本张 / 取消」
- 文件名比较忽略大小写，同一批内的重名也会被识别为冲突
- Windows 与 Android 均已支持

---

## 🐛 问题修复

- **修复替换同名文件后仍显示旧图**：Windows 上把图片内容替换但不改文件名，再次打开仍是旧图。现在图片与缩略图都会按文件修改时间重新读取。
- **修复合并共享文件夹在远端无法浏览**：手机端合并同名共享文件夹后，桌面端此前拿不到缩略图、也点不开图片，现在可以正常浏览。
- **修复已排除分区仍按大小写拆分**：排除记录也统一按不区分大小写归组。

---

## 🔄 升级说明

- 从 v1.5.x 直接覆盖安装即可，**设置、文件夹列表、共享源、已排除记录都会保留**。
- 版本号可在首页底部或「帮助 → 关于」中查看，应为 **V1.6.0**。

## 📦 安装包

| 平台 | 文件 | 说明 |
|------|------|------|
| **Windows** | `FrameFlow-v1.6.0-windows-x64.zip` | 解压后运行 `FrameFlow.exe`（64 位） |
| **Android** | `FrameFlow-v1.6.0-android.apk` | APK 安装包（需允许「安装未知来源应用」） |

### Windows 安装

1. 下载并解压 `FrameFlow-v1.6.0-windows-x64.zip` 到任意目录
2. 双击 `FrameFlow.exe` 运行

### Android 安装

1. 下载 `FrameFlow-v1.6.0-android.apk` 传到手机
2. 点击安装；如提示「未知来源」，请在系统设置中允许「安装未知应用」
